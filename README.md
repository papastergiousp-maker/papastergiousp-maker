## Signature project: Greek Banking Sector Analysis 2022 to 2024

Repo: https://github.com/papastergiousp-maker/greek-banking-sector-analysis
Live app: https://greek-banking-sector-analysis.streamlit.app/
Live dashboard: https://phytai.com/dashboard

An analysis of the four Greek systemic banks (Eurobank, Alpha Bank, Piraeus Bank, NBG), built from 12 official annual report PDFs.

- ETL with pdfplumber and pandas into a SQLite database, with tests that re-derive the KPIs
- SQL with CTEs and window functions for the KPIs
- 5-step banking DuPont, CAMELS ratings and peer benchmarking
- OLS forecast of Net Interest Income with ECB rate scenarios
- EBA-style adverse stress test with the CET1 impact
- Text-to-SQL: questions in plain English answered by the Claude API against the database
- 8-page Streamlit app, static Plotly dashboard, Excel model and slide deck

The findings and their numbers are in the project README.
